Technical foundation

A focused Django backend, made inspectable

The release uses server-rendered Django, behaviour-focused tests, a lightweight local setup, and a PostgreSQL release path. The product remains useful without an AI model or paid API.

  • Python 3.13
  • Django 5.2 LTS
  • Accessible server-rendered pages
  • Public behaviour tests
