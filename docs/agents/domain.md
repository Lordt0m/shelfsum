# Domain documentation

ShelfSum uses one shared product context.

- Read `CONTEXT.md` before exploring or changing product behaviour.
- Read relevant decision records under `docs/adr/` before reopening a consequential design choice.
- Use the glossary's exact terms in models, URLs, templates, tests, tickets, and documentation.
- If implementation exposes an important missing concept, update `CONTEXT.md` before adding competing vocabulary.
- If a proposed change conflicts with a decision record, state the conflict and the reason for reconsidering it.

Repository-wide workflow belongs in `AGENTS.md`; product language belongs in `CONTEXT.md`; hard-to-reverse technical decisions belong in `docs/adr/`.
