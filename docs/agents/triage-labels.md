# Triage labels

Use these exact status strings in local tickets.

| Status | Meaning |
| --- | --- |
| `needs-triage` | The ticket needs evaluation or decomposition. |
| `needs-info` | Work is waiting for missing information. |
| `ready-for-agent` | The ticket is sufficiently specified for autonomous implementation. |
| `ready-for-human` | The ticket needs a human decision or action. |
| `wontfix` | The ticket will not be actioned. |
| `in-progress` | Implementation is actively underway. |
| `complete` | Acceptance checks and verification have passed. |
